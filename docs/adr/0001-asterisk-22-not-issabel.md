# 0001 — Build on Asterisk 22 LTS with our own control plane, not on Issabel

- Status: accepted
- Date: 2026-11-25

## Context
Mira is a multi-tenant product sold for years, cloud and on-premise. Issabel is a single-tenant PHP PBX distribution around an older Asterisk with its own release cycle.

## Decision
Asterisk 22 LTS (PJSIP only) as the call engine behind Kamailio + RTPengine; Mira Core (Python) owns configuration, tenants, IVR, ACD rules and APIs. Issabel only as a stopgap for clients who need a PBX before Mira is ready.

## Consequences
We own the data model, APIs and upgrades. More work up front; telephony configs must be generated by Mira Core. See study, "Platform decision".
