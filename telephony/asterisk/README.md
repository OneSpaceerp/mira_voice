# telephony/asterisk/

Asterisk 22.12.0 LTS compiled from the official tarball (SHA256 checked), bundled pjproject, portable build (no `-march=native`), English and French prompts (ulaw, G.722). Two-stage Dockerfile: the runtime image gets only the Debian packages the binaries actually link against.

| File | Purpose |
| --- | --- |
| `Dockerfile` | Build and runtime image `mira/asterisk:<version>` |
| `entrypoint.sh` | Renders `templates/*.tmpl` (only `ARI_USER`, `ARI_PASSWORD` substituted), copies `/opt/mira/config/asterisk/*.conf` into `/etc/asterisk/mira/`, runs Asterisk as user `asterisk` |
| `config/pjsip.conf` | UDP transport on 127.0.0.1:5080 and the `mira-endpoint` / `mira-aor` / `mira-auth` templates (Path support, RTP bound to 127.0.0.1, one contact per extension) — used by the lab extensions; `endpoint_identifier_order = ip,auth_username,username` (`ip` = the identify module, which also matches Kamailio's `X-Mira-Trunk` header); `#tryinclude generated/pjsip_mira.conf` = trunks generated by Mira Core (0640, group `mira-config` gid 2701 shared with the Core image) |
| `config/sorcery.conf`, `config/extconfig.conf`, `templates/res_odbc.conf.tmpl`, `templates/odbc.ini.src` | **Realtime** (ADR 0006): endpoints / AORs / auths of every Mira extension come from PostgreSQL views (schema `asterisk`, read-only role `asterisk`) over ODBC; `pjsip.conf` objects are read first |
| `config/templates/ari.conf.tmpl` | ARI user for Mira Core; `channelvars = CHANNEL(linkedid)` so every channel in ARI JSON names its call (task 1.3) |
| `config/extensions.conf` | Lab dialplan, the helper subroutines (`mira-dial-extension`, `mira-unknown-number`, `mira-outbound` = call out through trunks in order, next trunk only on CHANUNAVAIL/CONGESTION) and `#tryinclude generated/extensions_mira.conf` — the per-tenant dialplan **generated by Mira Core** into a shared volume (read-only here) and reloaded over ARI |
| `config/modules.conf` | Autoload with an explicit noload list; every module Mira needs (app_queue, app_confbridge, app_amd, app_mixmonitor, res_ari, res_srtp) is checked by the tests |
| `config/*.conf` | Minimal configs so each used module loads cleanly; `manager.conf` keeps AMI off |

Asterisk's SIP, RTP and ARI ports are on 127.0.0.1 only — reach it through Kamailio and RTPengine, or ARI from the same host.
